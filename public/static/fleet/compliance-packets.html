Any software that surfaces or applies mortgage program rules (loan limits · guidelines · calculators) must clearly disclaim, cite official sources, and route decisions to licensed humans.
⚠ Every loan limit and program rule must be verified against the official source before production display. Stale data in a mortgage tool is a legal exposure — not a bug.
