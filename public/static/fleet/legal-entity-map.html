3 · Intercompany Agreements

Required · pre-launch

Every value flowing between related entities needs a signed agreement so the IRS, auditors, and courts see clean lines.

Agreement · Type A

Management Services Agreement

MOG provides shared admin, brand, marketing, and back-office to each operator. Operator pays MOG a documented management fee.

MOG ↔ every operator
Agreement · Type B

IP License Agreement

MortgageOS / GrowthOS / LearningOS retain IP; other operators license the software under documented terms with defined fees.

Software IPCos ↔ operators
Agreement · Type C

Referral / Cross-Sell Agreement

Formal referral fees between operators (e.g., TCP → Capital Ready → MortgageOS). Documented percentages, disclosed to clients.

Operator ↔ operator
Agreement · Type D

Sublease / Facilities Agreement

Any shared physical space needs a documented sublease with fair-market rent so no entity subsidizes another off-books.

Space-owner ↔ occupying entities
Agreement · Type E

Employee/Contractor Assignment

Which entity actually employs each person, and how time gets allocated across entities they support (with proper W-2/1099).

Employer ↔ employee ↔ served entities
Agreement · Type F

Nonprofit Firewall

McKnight Housing Initiative operates under strict independence — no private inurement, board-approved arms-length dealings only.

MHI ↔ all for-profit entities
