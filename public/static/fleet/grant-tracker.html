Grants.gov Cheat Sheet

Registration · workflow · minimum requirements

Everything you need — faithfully done.

Federal grants live on Grants.gov. Every submission must trace back to a valid SAM.gov registration, an AOR (Authorized Organizational Representative), and a completed applicant profile. Miss a step, miss the deadline.

Registration Workflow

  1. SAM.gov Active — entity registration current, UEI + CAGE issued
  2. Grants.gov Applicant Profile — matches SAM data
  3. Designate EBiz POC — official grants electronic-business contact
  4. AOR Registered — Authorized Organizational Rep can sign submissions
  5. Login.gov Set Up — MFA required for AOR access
  6. Workspace Created — practice submission before real deadline

Every Application Needs

  • SF-424 (application for federal assistance)
  • SF-424A / B (budget + assurances)
  • Project narrative (page-limited by opportunity)
  • Statement of need + logic model
  • Budget narrative + justification
  • Applicant capability statement
  • Certifications (debarment · lobbying · drug-free)
  • SF-LLL (lobbying disclosure) if applicable
  • Letters of support / MOUs
  • IRS determination letter (if nonprofit)

Common Pitfalls

  • SAM registration expires mid-application (72-hour lag to reactivate)
  • AOR credentials lost — no one can submit
  • Budget doesn't tie to narrative
  • Match funds unverified / uncommitted
  • Page-limit violations disqualify entire application
  • File-format wrong (only PDF for most attachments)
  • Submitting less than 24 hrs before close (system queue can fail)
  • Missing SF-LLL when lobbying activity exists

Post-Submission Sequence

  1. Submission Confirmation — receipt email within minutes
  2. Validation Confirmation — 24-48 hrs (may reject → resubmit)
  3. Agency Tracking Number — 5-7 days
  4. Review Period — 60-180 days depending on program
  5. Award or Denial Notice — via email + Grants.gov workspace
  6. Reporting Cadence Established — quarterly / annual per NOFO

Reporting Calendar
